# Edge AI-Based Multi-AMR Warehouse Fleet Coordination

An autonomous multi-robot fleet coordination system designed for dynamic smart warehouse environments. The project integrates a 3D digital twin simulation built in **Webots** with an interactive, real-time **React telemetry dashboard** over WebSockets.

---

## 📌 Features

- **Multi-Robot Simulation:** Multi-AMR setup (Festo Robotino / custom differential drive) navigating warehouse aisles.
- **Collision Avoidance & Routing:** Dynamic priority yielding and potential field navigation for congestion mitigation.
- **Digital Twin Telemetry:** Bidirectional WebSocket communication streaming live robot poses, battery state, speed, and mission status.
- **Mission Control Dashboard:** React-based UI displaying live 2D warehouse map overlays, fleet telemetry cards, and system logs.
